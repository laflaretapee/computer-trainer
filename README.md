## 📋 Возможности

### 🎹 Тренажёр слепой печати
- 5 уровней сложности — от главного ряда до полного текста с пунктуацией
- Цветные зоны для 10 пальцев на экранной клавиатуре
- Метрики в реальном времени: скорость (зн/мин), точность (%), время
- Защита от читинга: блокировка ввода после завершения упражнения

### 🖱️ Тренажёр мыши
- 5 упражнений: «Попади в цель», «Перетащи», «Двойной клик», «Правый клик», «Прокрутка»
- Система звёзд (1–3 ⭐) за каждое задание
- Звуковые эффекты (Web Audio API, отключаемо)

### 🎮 Геймификация
| Уровень | Звание | XP |
|---------|--------|----|
| 1 | 🥉 Новичок | 0–99 |
| 2 | 🥈 Пользователь ПК | 100–299 |
| 3 | 🥇 Опытный практик | 300–599 |
| 4 | 💎 Мастер мыши и клавиатуры | 600–999 |
| 5 | 👑 Гуру информатики | 1000+ |

**Бейджи:**
- 🚀 **Первый шаг** — завершить первое упражнение
- ⚡ **Быстрые пальцы** — скорость >100 зн/мин с точностью ≥90%
- 🖱️ **Мастер мыши** — все 5 заданий на 3 звезды
- 🧠 **Знаток теории** — тест на 100%
- 🏆 **Гуру практики** — набрать 500+ XP

### 🛡️ Защита от списывания (FocusGuard + TabGuard)
- Предупреждение перед стартом упражнения
- Мгновенное аннулирование результата при уходе с вкладки (0 XP)
- Защита от открытия второй копии в соседней вкладке (heartbeat)
- Журнал нарушений в панели учителя

### 🔄 Автообновление
- При выходе в интернет приложение проверяет наличие новой версии
- Загрузка обновлений без потери локальных данных учеников
- Работает тихо в фоне; не мешает офлайн-режиму

### 📊 Синхронизация успеваемости
- Данные учеников копятся локально в `localStorage`
- При наличии сети — автоматическая отправка на сервер учителя
- Экспорт/импорт JSON-пакета для сбора данных без интернета (через флешку)

## 🚀 Быстрый старт

```bash
# 1. Скачайте или клонируйте репозиторий
git clone https://github.com/laflaretapee/computer-trainer.git

# 2. Перейдите в папку
cd computer-trainer

# 3. Откройте в браузере
# Двойной клик по index.html
```

> **Не требует** Node.js, сервера или интернета для работы.  
> Всё запускается прямо из папки через браузер (`file://`).

## 👩‍🏫 Панель учителя

Войдите как **Учитель** на экране входа.

**Пароль по умолчанию:** `teacher123`  
*(Измените в `data/students.json` → поле `teacher_password`)*

**Возможности панели:**
- 📈 Таблица прогресса всех учеников (скорость, точность, XP, уровень)
- 🏅 Список полученных бейджей по каждому ученику
- 🚨 Журнал нарушений FocusGuard (попытки уйти с вкладки)
- 📥 Экспорт данных в JSON (для сбора с нескольких ПК)
- 📤 Импорт и слияние данных от других компьютеров
- 🌐 Настройка URL-эндпоинта для автосинхронизации
- 🔄 Включение/отключение TabGuard

## 🔧 Настройка

### Добавить учеников

Откройте `data/students.json` и добавьте учеников в список:

```json
{
  "teacher_password": "teacher123",
  "classes": {
    "7А": [
      { "id": 1, "name": "Алиев Алмас" },
      { "id": 2, "name": "Бекова Жанар" }
    ]
  }
}
```

### Сменить пароль учителя

В файле `data/students.json` измените значение поля `teacher_password`.

### Включить автосинхронизацию

В панели учителя введите URL вашего сервера в поле «Endpoint для телеметрии».  
Пример: `http://192.168.1.100:5000/sync`

### Обновить версию

После доработок обновите `version.json`:

```json
{
  "version": "1.2.0",
  "buildDate": "2026-11-13"
}
```

Ученические ПК подхватят изменения при следующем подключении к интернету.
