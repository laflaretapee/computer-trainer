# 📁 Папка `presentations/grade7/`

Сюда кидаешь все `.pptx` презентации для 7-х классов — одной кучей, без разбивки.

## Структура

```
presentations/
└── grade7/
    ├── Устройство_ПК.pptx
    ├── Файлы_и_папки.pptx
    ├── Правила_работы.pptx
    └── ...  ← любые другие .pptx
```

## Как запустить индексацию

1. Положи `.pptx` файлы в папку `grade7/`
2. Открой терминал в папке проекта
3. Запусти:
   ```
   python index_presentations.py
   ```
4. Скрипт создаст:
   - `indexed/<тема>/slide_01.png` — картинки слайдов
   - `data/content.json` — весь текст для тестов

## Результат

После индексации `data/content.json` будет содержать:
- Текст каждого слайда (для мини-тестов и теории)
- Пути к картинкам слайдов (для просмотра в тренажёре)
