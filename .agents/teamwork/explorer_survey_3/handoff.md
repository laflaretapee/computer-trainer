## 3. Caveats

1. **Offline Web Audio Support**: Web Audio API `AudioContext` is supported in all modern Chromium/WebKit/Gecko browsers without network requests, but browsers require user interaction (e.g., clicking a button) before audio playback can begin. Audio synthesis must therefore be triggered inside user click/keydown handlers.
2. **Screen Resolutions**: The interface must fit 1280x720, 1366x768, and 1920x1080 without overflowing or causing overlapping elements. Virtual keyboard and interactive mouse work areas must use fluid layouts (`max-width: 100%`, `clamp()`, `rem`/`vw` units).
3. **Data Parity Responsibility**: Both `data/students.json` and `data/students.js` exist. The application loads `data/students.js` in `<script src="data/students.js">`. Any update to student data must be reflected in both files.
